# 部分关节拟合结果使用 v3

状态：Accepted。批准依据为用户对 CR4 Q9 的明确答复。

## 背景与备选方案

全量结果以任务全序核对参数；部分结果还需描述未记录关节的控制工况。扩展 v2 的可选字段，或用 v3 区分新语义。

## 决策与理由

保留已有有效单一 dt 全量 v2 的读写，v3 承载部分结果或纯速度结果，包括记录通道、完整控制分组、保持目标和延迟作用范围。

## 影响与证据

回放和绘图须识别对应版本；原始轨迹文件延续原有张量字段。依据见 [CR4 研究记录](../.scratch/issue_4/research.md) 和 [CR4 规格](../.scratch/issue_4/spec.md)。
