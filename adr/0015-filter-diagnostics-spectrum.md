# 离线滤波诊断的频谱和相位口径

状态为 Accepted。批准依据为用户明确批准 CR6 Q7–Q9 作为最终 Specify 契约。

## 背景与选项

同一采集工具可以记录不同扫频范围，文件没有关节名或扫频频带元数据。需要在整段记录上比较不同设置对受激分量的影响，并展示原始测量的宽带频谱。整段加窗 FFT 能复用 CR5 验收的频率栅格和复相位。Welch 功率谱适合平滑噪声观察，分段长度会改变栅格，单独的功率谱也不足以计算时差。全段互相关可给出一个总滞后，不能直接给出批准的逐频最大时差变化。[研究记录](../.scratch/issue_4/research.md#cr6-滤波诊断与可视化研究)

## 决策与理由

采用去均值、周期 Hann 窗和整段实数 FFT。幅值与相位使用各自的有效条件，计算两次响应相对同一期望指令的最短相位差；沿用 CR5 高频能量求和方式。对幅值较弱的频点按数值可辨性筛选，并随极值报告覆盖范围。启用图形时从同一滤前复谱得到有物理单位的单边幅值谱。[已批准的接口](../.scratch/issue_4/interfaces.md#cr6-滤波诊断命令行与输出契约)

## 影响、局限与证据

有效覆盖会随数据和设置改变；单频相位只确定模一周期的时差。滤后信号在某频点消失时，该点仍能说明幅值衰减，相位失去参考。已用两种截止下的真实 X5、已知相位折返和退化短记录验证可行性。频谱及误差只描述当前记录，跟踪 RMSE 同时包含真实动力学跟踪误差。[临时实验](../.scratch/issue_4/research.md#cr6-两项临时-cpu-实验已执行)
