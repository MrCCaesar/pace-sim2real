# Issue #22 · 检查器接口

状态：Approved，随修订后的 Specify 获批。以下为项目检查器的接口契约。Ruff、pre-commit 和 Isaac Lab 的既有接口沿用上游行为，领域检查规则与样例见 [spec.md](spec.md)。

| 接口 | 输入、默认值与约束 | 输出与失败行为 |
| --- | --- | --- |
| 独立命令 `isaaclab-task-lint [--root PATH] [--package NAME]` | PATH 默认为当前项目根目录，必须可读取 pyproject.toml 与 src/。NAME 是项目任务包的 Python 标识符，默认从 pyproject.toml 的 project.name 将连字符替换为下划线后取得；发行名不同于导入名时显式指定。以项目包名推导扩展包名。 | 只读扫描，默认检查整个项目。退出 0 表示无违规，1 表示规则诊断导致失败，2 表示项目输入、配置、源码读取或语法解析失败。 |
| 结构检查 hook `isaaclab-task-lint` | 由 pre-commit 在消费仓库运行，可传同名命令参数。每次检查完整相关源码；不依赖变更文件列表。即使只删除被引用文件，也须触发。支持从包含该 hook 的 Git 仓库按修订号接入。 | 与独立命令相同。不得因工作目录位于另一项目而扫描 hook 提供方自身源码。 |
| 诊断记录 | 输入为路径、规则编号、出错位置、涉及符号及可确定的定义或期望目录。项目根相对路径；行列均从 1 开始，目录级诊断允许只给路径。 | 每项一行，包括位置、稳定规则 ID 和说明；按路径、位置、ID 稳定排序。错误定义在绑定位置之外时给出两处位置；未解析项写明原因。诊断写标准输出，妨碍扫描的错误写标准错误。 |
| 全库入口 `pre-commit run --all-files` | 现有 pre-commit CLI，在已安装开发依赖的项目根执行。按文件类型运行已配置的通用检查；结构 hook 对项目源码整体判定。 | 任一适用 hook 失败则全库验收失败。若格式 hook 改写了文件，需复查并重新执行至干净通过。 |

**扫描边界。** 索引 src/ 下所有项目 Python 源码与存根，包括新增和旧布局文件。从任务入口、环境定义和项目内的框架扩展发现组件，沿继承、组合、构造、实现绑定与资源声明继续检查仓库内相关文件，包括从包外引用的本地源码或配置。已知上游类型按其来源分类。通用 lint 单独覆盖仓库适用的 Python 文件。

**通过与失败。** 全库运行报告发现的环境和组件数，并分别列出组织违规、未解析绑定和缺少规则的计数。退出 0 要求覆盖扫描完成且以上三项均为零。ORG005 必须报告绑定位置（文件及从 1 开始的行列）、原始引用及未解析原因，退出 1。已定位但缺少适用组织规则的组件报 ORG008，退出 1。整个项目无法读取或解析属于输入错误，退出 2。

**兼容与运行条件。** 首版目标为 Python 3.12 及 [Research](research.md) 记录的 Isaac Lab v3.0.0 正式版外部模板及该标签的框架符号。检查器读取被检查项目的文本，执行检查无需在同一 Python 环境安装 Isaac Lab。跨项目验收使用独立的消费项目和固定 Git 修订。首次发布修订与实施顺序留到获批后的阶段。
