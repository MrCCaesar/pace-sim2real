## REQ-02-001：新增环境与随机动作运行

### Requirement ID

`REQ-02-001`

### 初始条件

- 当前项目及本地 Isaac Lab 依赖可用，Python 3.12、Isaac Sim + PhysX 验收环境可运行。
- 单个悬吊环境具有完整且有效的配置。

### 输入/触发条件

- 使用 `scripts/random_agent.py` 指定新增悬吊任务并运行单环境。

### 可观察行为

- 可以创建环境、reset 并持续处理随机关节位置动作。
- 运行过程中可以取得悬吊系统状态，并自动记录所需信息。

### 验收标准

- 环境创建、reset 和随机动作 step 流程能够执行，不因缺少任务、配置或动作接口而失败。
- 单环境运行产生可重新读取的记录文件。
- 运行步数或时长、退出方式及正常运行的完整判定待确认后补齐。

### 尚不明确的问题

- 新任务的标识、有限运行验收的步数或时长及退出方式。
- 是否要求 GUI、headless 或两种运行方式。
- 超出单环境的支持和验收范围。

## REQ-02-002：悬吊拓扑与躯干挂点

### Requirement ID

`REQ-02-002`

### 初始条件

- 加载 ANYmal D，并提供世界固定悬挂点、吊钩和躯干挂点配置。

### 输入/触发条件

- 创建或 reset 悬吊环境。

### 可观察行为

- 一根长绳连接世界固定点和吊钩。
- 四根短绳分别连接吊钩与机器人躯干四角的固定挂点。
- 世界固定点保持固定；机器人端挂点随所属躯干刚体共同运动。

### 验收标准

- 拓扑恰为一根长绳和四根短绳；每条绳的两端能够明确识别。
- 四个机器人端挂点位于躯干，而非脚端。
- 长绳与四根短绳通过同一个可运动的吊钩连接。

### 尚不明确的问题

- 固定点、吊钩与机器人初始位姿，长短绳的标称长度。
- 躯干挂点的连接刚体、局部坐标及稳定命名顺序。
- 吊钩的各绳连接位置、质量和惯量。
- 绳索质量、接触、缠绕与可视化的范围。

## REQ-02-003：自由悬吊与六自由度响应

### Requirement ID

`REQ-02-003`

### 初始条件

- REQ-02-002 的悬吊系统已创建，机器人和吊钩具有动力学状态。

### 输入/触发条件

- 推进仿真，并施加关节位置激励。

### 可观察行为

- 机器人基座可在绳索作用下产生三维平移和三维转动。
- 吊钩作为有质量的独立刚体参与运动。
- 基座运动是动力学输出，而不是指定的基座目标轨迹。

### 验收标准

- 机器人基座不固定在世界，也不直接按预设基座位姿轨迹强制移动。
- 不通过额外约束将基座限制为少于六自由度的运动。
- 可取得基座位姿及线速度、角速度，以检查其响应。
- 不要求单条激励同时激发六个分量，也不设未确认的最小位移或转角阈值。

### 尚不明确的问题

- 重力、初始状态、初始松弛或预拉伸及是否需要静置阶段。
- 是否保留地面和碰撞，以及接触对运行验收的影响。
- 验证各自由度响应的测试场景与数值容差。

## REQ-02-004：五根绳的单边弹性拉力

### Requirement ID

`REQ-02-004`

### 初始条件

- 每根绳都有标称长度，能够取得其两端当前状态。

### 输入/触发条件

- 绳端距离小于或大于标称长度，并随系统运动变化。

### 可观察行为

- 小于标称长度时，该绳不产生沿绳方向的拉力或推力。
- 超过标称长度时，该绳通过弹性伸长产生拉力。
- 绳索不能产生推力；允许伸长，不采用不可伸长的最大长度解释。

### 验收标准

- 上述拉力约束同时适用于长绳和四根短绳。
- 分别在松弛和伸长场景检查拉力；任何状态都不能出现绳索推力。
- 具体伸长量对应的拉力、临界长度行为及数值容差在确认力律后补齐。

### 尚不明确的问题

- 力律、刚度和阻尼；标称长度处的力。
- 长度超过标称值但正在快速缩短时，是否允许阻尼使总张力归零。
- 是否忽略绳索质量，是否考虑拉力上限或断绳。
- 绳端重合等退化几何场景的处理要求。

## REQ-02-005：关节激励轨迹执行

### Requirement ID

`REQ-02-005`

### 初始条件

- 悬吊环境已创建，存在按时间定义的关节位置目标。

### 输入/触发条件

- 执行一条指定的关节激励轨迹；随机动作运行作为独立验收场景。

### 可观察行为

- 轨迹目标作为关节位置输入驱动机器人。
- 基座运动与短绳拉力作为仿真响应被记录。

### 验收标准

- 能执行指定关节位置轨迹，并产生可重新读取的基座状态和短绳拉力记录。
- 不以随机动作运行代替指定轨迹执行验收。
- 输入格式、关节映射、时间推进、起止及异常输入判定在确认后补齐。

### 尚不明确的问题

- 输入使用外部轨迹文件、内建 chirp，还是两者都需要。
- 时间戳、采样时钟、插值、轨迹初态及结束行为。
- 是否沿用现有 PACE 执行器配置；是否排除旧采集脚本额外注入的辨识参数。
- 指定轨迹的验收样例及参数。

### 尚不明确的问题

## REQ-02-007：基座状态记录

### Requirement ID

`REQ-02-007`

### 初始条件

- 悬吊环境正在运行，基座状态可读取。

### 输入/触发条件

- 使用 random_agent 或指定轨迹流程推进环境。

### 可观察行为

- 自动记录基座位置、姿态、线速度和角速度。

### 验收标准

- 运行后可重新读取包含四类基座状态的数据文件。
- 字段的参考点、坐标系、单位、姿态表示、采样时点和完整性判定待确认后补齐。

### 尚不明确的问题

- 基座指根刚体坐标原点还是质心。
- 位置、姿态、线速度和角速度各自的表达坐标系与单位。
- 姿态使用四元数还是其他表示，以及分量顺序。

## REQ-02-008：四根短绳拉力记录

### Requirement ID

`REQ-02-008`

### 初始条件

- 四根短绳已按 REQ-02-002 连接，并具有可读取的拉力。

### 输入/触发条件

- 使用 random_agent 或指定轨迹流程推进环境。

### 可观察行为

- 分别记录四根短绳的拉力，能够将记录对应到各自躯干挂点。

### 验收标准

- 数据文件包含四根短绳各自的拉力记录。
- 能区分四根绳，不能仅以合力或平均力替代。
- 松弛绳的记录符合 REQ-02-004 的无拉力、无推力约束。
- 拉力表示、时序和数值一致性判定待确认后补齐。

### 尚不明确的问题

- 记录非负张力标量、三维力向量，还是两者。
- 力的作用对象、坐标系、单位及四根绳的固定顺序。
- 是否额外记录长绳张力、绳长和绳索端点状态用于诊断。

## REQ-02-009：自动落盘与可重新读取

### Requirement ID

`REQ-02-009`

### 初始条件

- 新环境具有记录目标位置，必需字段来自 REQ-02-007 和 REQ-02-008。

### 输入/触发条件

- 通过 random_agent 或指定轨迹流程启动、推进和结束运行。

### 可观察行为

- 无需单独手工抄录，即可得到所需信息的数据文件。
- 文件可由读取工具重新加载。

### 验收标准

- 两种运行流程均自动留下可加载的基座状态和四根短绳拉力记录。
- 不仅向控制台输出，也不只保存在运行时内存中。
- 格式、路径、时间戳、采样频率、reset 分段、退出保存及完整性判定待确认后补齐。

### 尚不明确的问题

- 文件格式、默认目录、重名或覆盖策略、运行配置元数据。
- 按物理步还是控制步采样，积分前还是积分后采样。
- 时间戳、样本对齐、reset 和 episode 的区分。
- 正常退出、Ctrl+C、异常退出分别应保证什么数据。
